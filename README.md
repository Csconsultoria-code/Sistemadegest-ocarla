# Sistema da Carla

Sistema simples de gestão: financeiro (receitas e despesas), leads, clientes, pasta de documentos por cliente, serviços e meta 10x.

- `index.html`: código da página (HTML, CSS e JavaScript em um único arquivo).

## Importante

- A página foi feita para rodar como artefato do Claude. Os dados (clientes, receitas, despesas, leads) e os arquivos enviados ficam no banco do próprio artefato, não neste repositório. Aberta fora do Claude, a página mostra a tela de login, mas não carrega dados.
- A tela de login é só uma trava de tela. Ela guarda apenas um hash da senha, mas qualquer pessoa que consiga abrir o código pode contorná-la. O controle de acesso de verdade é o compartilhamento do artefato no Claude.
- Não coloque dados de clientes neste repositório.
